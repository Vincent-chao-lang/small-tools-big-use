照片里多余的人，怎么去掉又不怕外传？

旅游照背景里杵着个路人、合影里多了个不想留的人、产品图上有个杂物——要去掉它，办法不止一种，但"照片会不会被传走"这件事，各家差别很大。

本页对应工具：照片去物 · Windows

先问一句：这张照片能不能传出去

去物这件事，技术上都做得到。真正的分水岭是：你愿意把原图交给谁。

会让人犹豫的照片，通常就这几类：

  • 有孩子的。幼儿园活动照、家庭出游照，一旦上了别人的服务器，你没法收回。
  • 有家里的。客厅、门牌、车、窗外的楼栋，都能被拿来推位置。
  • 证件、票据、样片。身份证照、合同照片、给客户拍的产品图，很多是受托内容。
  • 人像。人脸是敏感信息里最敏感的一类，这一点在《个人信息保护法》里写得很清楚。

如果你只是修一张风景照发朋友圈，随便哪个 App 都行。但如果属于上面四类，选工具的第一条标准就变成了：它要不要把图传走。

三条路，各自的真实成本

路子一：手机自带修图 / AI 修图 App（最方便）

现在很多手机相册自带"消除"功能，圈一下就能抹掉。第三方 App 更夸张，效果甚至更好。

代价是三点：

  • 多数要联网。所谓"AI 消除"基本是把图送到云端算，手机上跑不动那么大的模型。
  • 免费额度有限。抹几张就提示开通会员，长期用是订阅制。
  • 效果不稳。同一张图换个角度就可能糊成一片，尤其是有透视的地面、栅栏、水面。
适合：随手修、不敏感的照片、只想省事。不适合：孩子照片、客户素材、需要可控质量。

路子二：Photoshop 内容识别填充（效果上限最高）

会 PS 的人用"内容识别填充"或"生成式填充"，能把人抹得几乎看不出痕迹，还能自己修边缘。质量确实最好。

门槛也真实存在：

  • 要会选区、要懂图层、要会补边缘，新手抹完常常留一块"发糊的补丁"。
  • 正版订阅是一笔持续支出，不是买断。
  • 生成式填充这类功能本身依赖云端算力，敏感图要另想办法（比如关掉云端功能，只用本地算法）。

路子三：本地离线去物工具（涂一下，本机算）

这一类工具的思路是把"填补"这件事放在你自己电脑上做：用红笔把要多去掉的东西涂满，点一下，算法在原处补出一块和周围协调的背景。

本站的 照片去物 就是这种：Windows 上装好即用，算法随安装包一起落地，不联网下载、不联网校验，照片全程留在本机；单次处理大约 1 秒。

它换来的不是"效果最强"，而是照片不出门这件事上的确定性——你可以拔掉网线再跑一遍，效果一样。

三条路横向对比

办法照片会上传要联网效果上限花钱方式适合
手机 / AI App多数会多数要中订阅 / 限次随手修、不敏感
Photoshop看功能看功能高订阅要交付质量、会 PS
本地去物工具不会不用中上买断孩子照、客户素材、批量修图

怎么涂，效果差别很大（这几条比工具更重要）

  1. 涂满，宁可多出一点。涂少了会留半只手、半只脚；涂多了算法只是多补一点背景，代价小得多。
  2. 一次只处理一块。人、垃圾桶、电线杆分开涂、分开跑，比一口气全涂掉好得多。
  3. 沿结构走。地面、墙面、天空这种"纹理连续"的区域最容易补好；涂到画面结构断点（比如墙角）时，分两次涂更稳。
  4. 大面积先别硬来。涂抹范围超过一定尺寸（这款工具是 450 px 左右会提示），可以勾选"快速"模式，用一点细节换速度。
  5. 补完看边缘。真正露馅的地方通常在交界处，放大到 100% 看一眼再发。

说清楚它做不到什么

这一节是给准备付钱的人看的，丑话在前面：

  • 它补的是背景，不是许愿池。涂掉一个人，不会凭空长出一只猫、一栋楼；它只会按周围内容把这块填自然。
  • 细结构可能不够锐利。发丝、纱网、栅栏、密集条纹这类东西，补出来容易发糊。
  • 一次一张，没有批量。批量只适合机位固定的同位置瑕疵（比如监控截图），不适合旅游照。
  • 只输出 PNG。无损，但文件比原 JPEG 大不少。
  • 只有 Windows 版。手机、Mac 上用不了。

常见追问

拔网线还能用吗？
能。算法跟安装包一起装到本地，处理过程不需要网络。这也是它和在线修图工具最本质的差别。
处理一张要多久？
单次约 1 秒，涂的范围越大越慢。
能把人整个"重画"成另一个人吗？
不能，也不该这么用。它擅长的是把画面里多余的一块补成背景。遮挡物后面的东西它也不会"猜"出来。
要显卡吗？
不需要独立显卡，普通电脑就能跑，慢一点而已。
修完的照片会不会带水印或元数据？
导出的是普通 PNG，具体以实际软件行为为准，发之前建议自己点开属性看一眼。
