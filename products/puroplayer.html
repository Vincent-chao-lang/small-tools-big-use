坦诚的边界（信任，而非瑕疵）

有些功能我们刻意不做，因为它们和"隐私"冲突：

  • 不记录任何播放历史（连"上次看到哪"都没有）
  • 不扫盘、不做媒体库 / 缩略图
  • 不云同步、不账号体系
  • 不内置转码 / 剪辑 / 投屏
少做这些，是为了把你视频的出口，守住。
口径说明（如实）：当前分发档未开启系统级 App Sandbox，"断网"由代码层零联网 + 解码内核网络插件裁剪保证，并非操作系统层封锁；当前安装包为开发者签名档（ad-hoc），Mac 首次打开需右键「打开」一次，Windows 同理需一次授权。正式规模化售卖前会解决签名公证。我们不说"绝对离线 / 系统层禁止联网 / 100% 不传数据 / 最强最安全"。

发货与安装说明

发货内容：安装包下载链接（+ 提取码）或激活方式，下单后按对应方式发送。

Mac 安装：下载 .dmg 双击打开，把 PuroPlayer.app 拖进「应用程序」。首次打开若提示「无法验证开发者」：在访达里对 app 右键（Control-点击）→ 打开，确认一次即可，之后可正常双击。

Windows 安装：下载 .msi 双击按提示安装即可。

提示：当前安装包为开发者签名档，极少数系统会要求上述一次授权。介意「即装即用零门槛」体验的用户，建议等正式公证版。

常见问题

真的不联网？怎么证明？
代码层无联网逻辑，内嵌解码内核网络类插件已全部剔除。应用内「自证」按钮可现场查看插件清单与权限，自己复核。
支持哪些格式？
基于 libVLC，MP4/MKV/MOV/AVI/FLV/WMV/TS/WebM 等主流格式基本通吃，支持 4K 硬解。
需要注册登录吗？
不需要。打开即用，零账户零注册，无观看记录上传。
会扫描别的文件吗？
不会。只读取你手动选定的视频，不扫全盘、不做媒体库。
Mac / Win 都支持？
都支持。Mac 兼容 Apple 芯片与 Intel；Windows 支持 10/11 64 位。下单选对应版本或双端通用。
有广告 / 会员 / 推荐？
都没有。无广告、无会员、无开屏、无内容推荐。
能投屏 / 转码 / 剪辑？
不能，也刻意不做——会引入联网或外部依赖，与隐私定位冲突。它是纯粹的本地播放器。
买了怎么拿怎么装？
发货为安装包下载链接（或卡密），按「发货与安装说明」几步装好；装不上我们包解决。
